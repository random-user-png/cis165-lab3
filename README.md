# cis165-lab3

In diamond.cpp, the output statements create the required shape by positioning the asterisks with spaces. I counted spaces that were difficult to see by selecting them with my cursor.
In game_time.cpp, integer division gives the number of whole hours, while the remainder function gives the number of remaining minutes. These two values are then displayed together. 78 / 60 is 1 with a remainder of 18. 144 / 60 is 2 with a remainder of 24. The difference between 144 and 78 is equal to 66. 66 / 60 is 1 with a remainder of 6.
The assignment asks to store calculations in variables before using cout so their values can later be recalled at any time.
